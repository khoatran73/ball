## Getting Started

### Prerequisites

Before you begin, ensure you have the following installed:

- Node.js (version >= 20.0)
- Yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/khoatran73/ball.git
   cd ball
   ```

2. Navigate to the backend directory and install dependencies:

   ```bash
   cd backend
   yarn install
   ```

3. Start the NestJS server:

   ```bash
   yarn start
   ```

4. Open a new terminal, navigate to the frontend directory, and install dependencies:

   ```bash
   cd ../frontend
   yarn install
   ```

5. Start the Next.js application:

   ```bash
   yarn dev
   ```

6. Open your web browser and navigate to `http://localhost:3000` to see the application in action.
